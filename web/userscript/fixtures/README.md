# Real store pages

Cleaned copies of real Tesco and Dunnes pages, saved with the helper's **Save page for Claude** button.
They let the helper be fixed and tested against the stores' real markup without anyone needing your account.

Useful pages (save each while signed in, with the helper installed):

| File | Page |
|---|---|
| `tesco-product.html` | Any product page, e.g. tesco.ie/shop/en-IE/products/292769876 |
| `tesco-product-in-basket.html` | The same product after pressing Add (shows the quantity controls) |
| `tesco-product-out-of-stock.html` | A product that's out of stock |
| `tesco-orders.html` | My orders: the list of past orders |
| `tesco-order.html` | One past order, opened |
| `dunnes-…` | The same pages on dunnesstoresgrocery.com |

The helper removes scripts, form values, emails, phone numbers, Eircodes and long numbers, and any words you
type when it asks (your name, street). **Open each file in a text editor and search for your name, address and
order numbers before committing it.** Then put the files here and push, or attach them to a Claude conversation.
